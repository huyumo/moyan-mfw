# 开发者模式开关 + 独立开发者密码验证 - 实现计划（修订版）

## 核心设计

开发者密码是**独立于登录密码**的第二个密码字段，存储在 User 实体的 `developerPassword` 列中（bcrypt 哈希）。只有 `isDeveloper === 1` 的用户才有此字段。

```
DEV 页面可见 = isDeveloper(后端身份) && devModeEnabled(前端开关已开启)
开启 devModeEnabled = 通过 developerPassword 验证
```

## 数据流

```
开发者首次使用 -> 调用 POST /auth/set-developer-password 设置开发者密码（需验证登录密码）
                                ↓
用户打开设置面板 -> "通用"Tab 显示开发者模式开关（仅 isDeveloper 可见）
                                ↓
点击开关 ON -> 弹出开发者密码输入框 -> 调用 POST /auth/verify-developer
                                ↓
后端验证：isDeveloper === 1 && verifyPassword(input, user.developerPassword)
                                ↓
成功 -> devModeEnabled = true -> loadPermissions 刷新菜单 -> DEV 菜单出现
失败 -> 提示错误，开关保持 OFF
                                ↓
点击开关 OFF -> 直接 devModeEnabled = false -> loadPermissions -> DEV 菜单消失
```

 * 开发者密码哈希
 * @description 开发者模式独立密码，使用 bcrypt 加密，仅 isDeveloper=1 的用户有值

@Column({ type: 'varchar', length: 255, nullable: true, comment: '开发者密码哈希 - 开发者模式独立密码，bcrypt 加密' })

### 后端：验证 + 设置接口

#### 3. AuthService 新增两个方法
**文件**: `packages/base/src/backend/src/modules/sys/auth/auth.service.ts`

```typescript
/**
 * 验证开发者密码
 */
async verifyDeveloperPassword(userId: string, password: string): Promise<boolean> {
  const user = await this.userRepository.findOne({ where: { id: userId } });
  if (!user) throw new BusinessException('用户不存在', 404);
  if (user.isDeveloper !== 1) throw new BusinessException('当前用户不是开发者', 403);
  if (!user.developerPassword) throw new BusinessException('未设置开发者密码', 400);
  const isValid = await verifyPassword(password, user.developerPassword);
  if (!isValid) throw new BusinessException('开发者密码错误', 400);
  return true;
}

/**
 * 设置开发者密码（需验证登录密码）
 */
async setDeveloperPassword(userId: string, loginPassword: string, developerPassword: string): Promise<void> {
  const user = await this.userRepository.findOne({ where: { id: userId } });
  if (!user) throw new BusinessException('用户不存在', 404);
  if (user.isDeveloper !== 1) throw new BusinessException('当前用户不是开发者', 403);
  // 验证登录密码确认身份
  const isValid = await verifyPassword(loginPassword, user.password);
  if (!isValid) throw new BusinessException('登录密码错误', 400);
  // 哈希并保存开发者密码
  const hashed = await hashPassword(developerPassword);
  await this.userRepository.update(userId, { developerPassword: hashed });
}
```

#### 4. AuthController 新增两个端点
**文件**: `packages/base/src/backend/src/modules/sys/auth/auth.controller.ts`

```typescript
@Post('verify-developer')
@HttpCode(HttpStatus.OK)
@ApiBearerAuth('Authorization')
@ApiOperation({ summary: '验证开发者密码', description: '开启开发者模式前验证身份' })
async verifyDeveloper(@User() user: UserDto, @Body() body: { password: string }) {
  if (!body.password) throw new BadRequestException('密码不能为空');
  await this.authService.verifyDeveloperPassword(user.id, body.password);
  return ApiResponseUtil.success(true, '验证成功');
}

@Post('set-developer-password')
@HttpCode(HttpStatus.OK)
@ApiBearerAuth('Authorization')
@ApiOperation({ summary: '设置开发者密码', description: '设置开发者模式独立密码，需验证登录密码' })
async setDeveloperPassword(@User() user: UserDto, @Body() body: { loginPassword: string; developerPassword: string }) {
  if (!body.loginPassword || !body.developerPassword) throw new BadRequestException('参数不能为空');
  await this.authService.setDeveloperPassword(user.id, body.loginPassword, body.developerPassword);
  return ApiResponseUtil.success(null, '开发者密码设置成功');
}
```

### 前端：状态管理

#### 8. auth-store 新增 devModeEnabled 状态
**文件**: `packages/base/src/frontend/src/store/auth-store.ts`

```typescript
const devModeEnabled = ref<boolean>(false);
const canSeeDevPages = computed(() => !!user.value?.isDeveloper && devModeEnabled.value);
const hasDeveloperPassword = ref<boolean>(false); // 是否已设置开发者密码（从后端获取）

// 开启开发者模式（弹验证弹窗）
async function enableDevMode(): Promise<void> {
  if (!hasDeveloperPassword.value) {
    // 未设置开发者密码 -> 弹出设置弹窗
    MfwPopup.open({ title: '设置开发者密码', component: DeveloperPasswordForm, ... });
    return;
  }
  // 已设置 -> 弹出验证弹窗
  MfwPopup.open({
    title: '开发者模式验证',
    component: DeveloperVerifyForm,
    on: { confirm: async () => {
      devModeEnabled.value = true;
      if (currentApp.value) await loadPermissions(currentApp.value.appId);
    }}
  });
}

// 关闭开发者模式
async function disableDevMode(): Promise<void> {
  devModeEnabled.value = false;
  if (currentApp.value) await loadPermissions(currentApp.value.appId);
}
```

修改 `transformPermissionMenu`：用 `canSeeDevPages.value` 替代 `user.value?.isDeveloper`。
修改 `clearToken`：登出时 `devModeEnabled.value = false`。
修改 `loadPermissions`：成功后检查 `hasDeveloperPassword`（从响应中读取或单独判断）。

关于 `hasDeveloperPassword` 的获取：在 `getUserPermissions` 响应中新增一个字段，或在 `getCurrentUser` 响应中新增。最简方案是在 `getCurrentUser` / `fetchUserInfo` 响应中增加 `hasDeveloperPassword: boolean` 字段。

## 安全性

- 开发者密码独立存储（bcrypt 哈希），与登录密码完全隔离
- 设置开发者密码需验证登录密码（防止 session 劫持后设置）
- `devModeEnabled` 不持久化（内存状态），刷新后自动关闭
- 后端 `getUserPermissions` 仍按 `isDeveloper` 过滤，前端开关是额外控制层
- 路由守卫检查 `canSeeDevPages`（= `isDeveloper && devModeEnabled`）
- 非开发者用户看不到开发者模式开关（`v-if="isDeveloper"`）
