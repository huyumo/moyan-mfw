## 在 picker 目录下编写 alimap-picker 组件

### 概述

参考 `E:\YunYi\网约车自选小程序\代码\admin\src\components\alimap` 的高德地图选点组件，在 `packages/base/src/frontend/src/components/picker/alimap-picker/` 下创建 `MfwAlimapPicker` 组件，遵循现有 picker 组件（icon-picker、app-selector 等）的代码结构和命名规范。

用户选择：
- **AMap 配置方式**：全局配置对象 — 创建 `configureAmap()` 函数，应用初始化时调用一次
- **实现范围**：包含选点组件 + ProvinceCityDistrict 省市区数据工具

### 新增文件清单（共 6 个新文件 + 3 个修改）

#### 1. `packages/base/src/frontend/src/components/picker/alimap-picker/amap-config.ts`（新增）

全局 AMap 配置与 SDK 加载器：

- 模块级 `amapConfig` 对象存储 `key`、`securityJsCode`、`version`（默认 `'2.0'`）、`plugins`
- `configureAmap(config: AmapConfig)` — 应用初始化时调用，设置 key 和 securityJsCode
- `getAmapConfig()` — 获取当前配置
- `loadAmapSdk()` — 基于 `@amap/amap-jsapi-loader` 加载 SDK，自动设置 `window._AMapSecurityConfig`，返回 `Promise<typeof AMap>`；内部缓存加载结果避免重复加载

#### 3. `packages/base/src/frontend/src/components/picker/alimap-picker/province-city-district.ts`（新增）

省市区数据工具类，参考原 `provinceCityDistrictData.ts`：

- `ProvinceCityDistrict` 类，使用 AMap `DistrictSearch` 获取行政区划树
- 单例模式，模块级缓存（内存 Map，不依赖外部 DB 类）
- `getSimplyData()` — 返回简化树结构 `SimplyDataItem[]`
- 使用 `loadAmapSdk()` 加载 SDK
- 通过 `getProvinceCityDistrict(options?)` 工厂函数获取实例

#### 4. `packages/base/src/frontend/src/components/picker/alimap-picker/index.tsx`（新增）

主组件 `MfwAlimapPicker`，使用 `defineComponent` + TSX（与 icon-picker、app-selector 一致）：

**核心行为**（移植自参考 `pointSelect.vue`，修复已知问题）：
- **onMounted** 中初始化：调用 `loadAmapSdk()` → 创建 `AMap.Map` → 获取城市信息 → 创建可拖拽 Marker → 逆地理编码初始位置
- **onBeforeUnmount** 中销毁地图实例释放资源
- **地点搜索**：`ElAutocomplete` + `AMap.PlaceSearch`，搜索结果显示名称+地址
- **手动经纬度输入**：`ElInput` + 正则验证（lat `-90~90`，lng `-180~180`），"设置"按钮定位
- **拖拽选点**：Marker `dragend` 事件触发逆地理编码
- **逆地理编码**：`AMap.Geocoder.getAddress()` 获取完整地址信息，emit `update:modelValue` 和 `change`
- **disabled 模式**：隐藏搜索栏，Marker 不可拖拽
- **地图容器 ID**：使用 Vue 3.5 的 `useId()` 生成唯一 ID（替代参考代码的 `MoUitls.randomString()`）
- **watch modelValue**：外部值变化时同步 Marker 位置

**修复参考代码的问题**：
- 移除未使用的 `computed`、`index`（formCard）导入
- `streetNumber` 统一 camelCase
- `AMapLoader.load` 从 setup 移至 onMounted
- 添加错误处理（catch 不再静默吞掉）
- 移除对 `@/config`、`@/lib/uilt.mo` 的外部依赖

**渲染结构**（JSX）：
```jsx
<div class="mfw-alimap">
  {/* 地址展示面板 */}
  <div class="mfw-alimap__panel">
    <div class="mfw-alimap__name">{markerData?.name}</div>
    <div class="mfw-alimap__address">{markerData?.address}</div>
  </div>
  {/* 地图区域 */}
  <div class="mfw-alimap__box">
    {!disabled && (
      <div class="mfw-alimap__search">
        <ElAutocomplete ... />  {/* 地点搜索 */}
        <ElInput ... />         {/* 经纬度输入 + 设置按钮 */}
      </div>
    )}
    <div id={mapId} style={{ height, width }} />
  </div>
</div>
```

### 使用方式示例

**应用初始化时配置**：
```typescript
import { configureAmap } from 'moyan-mfw-base/frontend';

configureAmap({
  key: 'your-amap-key',
  securityJsCode: 'your-security-code'
});
```

**组件使用**：
```vue
<script setup>
import { MfwAlimapPicker } from 'moyan-mfw-base/frontend';
const location = ref();
</script>

<template>
  <MfwAlimapPicker v-model="location" :height="'400px'" @change="onLocationChange" />
</template>
```

**省市区数据工具**：
```typescript
import { getProvinceCityDistrict } from 'moyan-mfw-base/frontend';

const pcd = getProvinceCityDistrict({ level: 3 });
const tree = await pcd.getSimplyData();
```
