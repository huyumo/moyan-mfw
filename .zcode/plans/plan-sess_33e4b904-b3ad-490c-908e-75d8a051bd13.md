## 需求

在偏好设置面板 → 通用标签页下添加版本号展示，版本号从业务层的 `demo/frontend/package.json` 的 `version` 字段读取。

## 数据流设计

```
demo/frontend/package.json (version: "1.0.0")
  → main.ts: import pkg from '../package.json'
    → createBaseAdminApp({ appVersion: pkg.version })
      → app.provide('mfw:appVersion', version)
        → AdminLayout.vue: inject('mfw:appVersion')
          → SettingsPanel.vue: :version="appVersion"
            → 通用标签页显示: "版本号 v1.0.0"
```

使用 Vue 的 `provide/inject` 机制（与代码库中已有的 `mfw:menuTrees` 模式一致），版本号作为只读的应用级配置传递，不持久化到 localStorage。

## 修改清单

### 1. `packages/base/src/frontend/src/layouts/panels/settings-panel-text.ts`
- 新增文本标签：`versionLabel: '版本号'`

### 2. `packages/base/src/frontend/src/layouts/panels/SettingsPanel.vue`
- 新增 `version?: string` prop
- 在通用标签页（`name="general"`）底部添加版本号展示，使用已有的 `mfw-admin-switch-item` 样式呈现只读信息

### 3. `packages/base/src/frontend/src/create-base-admin-app.ts`
- 在 `BaseAdminBootstrapOptions` 接口中新增 `appVersion?: string` 字段
- 在 `createBaseAdminApp` 函数中通过 `app.provide('mfw:appVersion', options.appVersion ?? '')` 注入版本号

### 4. `packages/base/src/frontend/src/layouts/AdminLayout.vue`
- 通过 `inject` 获取 `mfw:appVersion`
- 向 `SettingsPanel` 组件传递 `:version="appVersion"` prop

### 5. `demo/frontend/src/main.ts`
- 新增 `import pkg from '../package.json'`（Vite 原生支持 JSON 导入）
- 在 `createBaseAdminApp` 调用中传入 `appVersion: pkg.version`

## 不需要修改的文件

- `vite.config.ts` — 无需 `define` 注入，Vite 原生支持 JSON 导入
- `layout-store` 相关文件 — 版本号不是布局/样式状态，不纳入 store
- `layout-types.ts` — 版本号不是布局配置，不纳入 `LayoutStyleConfig` 或 `AdminNavigationConfig`
