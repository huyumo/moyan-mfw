## 目标

`/api/route-sync/check` 接口只返回两种情况：需要同步 / 不需要同步。非开发者调用时直接返回 `needsSync: false`，不再抛异常或返回错误码。

## 修改文件

**`packages/base/src/backend/src/modules/sys/route-sync/route-sync.controller.ts`**

修改 `check()` 方法，移除 `requireDeveloper` 权限检查，非开发者直接返回 `needsSync: false`：

```typescript
async check(@User() user: UserDto, @Body() body: AppTypeMenuConfig[]) {
  // 非开发者直接返回不需要同步
  if (user.isDeveloper !== 1) {
    return ApiResponseUtil.success({ needsSync: false }, '检查成功');
  }
  const needsSync = await this.routeSyncService.checkSyncNeeded(body);
  return ApiResponseUtil.success({ needsSync }, '检查成功');
}
```

移除 `requireDeveloper` 私有方法和 `ForbiddenException` 导入。

`sync()` 方法保持不变（仍保留 `requireDeveloper` 权限校验，同步操作需要开发者权限）。

## 前端无需修改

前端 `route-sync-button/Index.vue` 中 `visible` 依赖 `authStore.user?.isDeveloper`，非开发者本就不会显示按钮，不会调用此接口。改动仅保证即使直接调用也返回正常的 200 响应。
